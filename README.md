# To-Do Web Application (Django)

Веб-приложение для управления личными задачами и планами, разработанное на фреймворке **Django**.

---

## 📌 Описание проекта

Проект представляет собой интерактивный менеджер задач (To-Do List). Пользователи могут создавать новые задачи, просматривать подробные сведения, редактировать содержимое, отмечать их как выполненные и удалять.

---

## ✨ Основной функционал

- **CRUD-операции:**
  - **Create:** создание новых задач с заголовком и подробным описанием.
  - **Read:** просмотр списка всех задач и отдельной страницы конкретной задачи.
  - **Update:** редактирование существующих задач и изменение их статуса (выполнено / не выполнено).
  - **Delete:** безопасное удаление задач с подтверждением.
- **Сортировка и фильтрация:** упорядочивание задач по дате создания и статусу выполнения.
- **Пагинация:** удобное отображение списка задач при большом их количестве.
- **Админ-панель:** управление всеми записями базы данных через стандартную панель администратора Django.

---

## 🛠 Технологии

- **Язык программирования:** Python 3.x
- **Фреймворк:** Django
- **База данных:** SQLite3 (по умолчанию)
- **Шаблонизатор:** Django Templates (HTML/CSS)
